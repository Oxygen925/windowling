## 2. 설계

### 2.1 다국어 (UI-01)
- 문자열은 실행 파일 옆 `lang/<코드>.toml` (평평한 `key = "문구"`). `ko`, `en` 동봉. 없는 키는 영어 → 키 이름 순으로 대체.
- 설정 `[display] language = "auto"`(Windows 표시 언어) | `"ko"` | `"en"`. 바꾸면 메뉴·창 문구를 즉시 다시 읽는다.
- 로그는 번역하지 않는다 (진단용, 지금처럼 한국어).
- AI 안내문(instructions)은 영어 그대로 (모델 입력).

### 2.2 아이콘 (UI-02)
- `tools/assets/gen_app_icon.ps1` 로 16~256px 다중 크기 `.ico` 생성 → 리소스(`app.rc`)로 실행 파일·트레이·창에 사용.

### 2.3 메뉴 (UI-03)
- 트레이: 정보 / 대화 열기 / 펫 ▶ (추가·바꾸기·제거·다시 읽기·숨기기·행동 일시정지) / AI ▶ / 화면 관찰 ▶ / 음성 읽기 / ─ / 캐릭터 관리… / 설정… / 도움말(환영 창) / 폴더 ▶ / ─ / 종료.
- 펫 우클릭: 이 펫과 대화 / 캐릭터 바꾸기 ▶ / 이 펫 제거 / 숨기기 / ─ / 캐릭터 관리… / 설정….
- **메뉴 명령 ID 는 바꾸지 않는다** (시나리오가 쓰는 106·110·113~120 등 유지).

### 2.4 창 공통 (UI-04~UI-09)
- Win32 + 직접 배치(대화창과 같은 방식). DPI 대응.
- **다크 모드 (추천, 미확정):** 문서화된 API 만 쓴다.
  - 제목 표시줄 `DWMWA_USE_IMMERSIVE_DARK_MODE`, 배경·글자 `WM_CTLCOLOR*`, 버튼·목록·스크롤 `SetWindowTheme(L"DarkMode_Explorer")`, 입력·콤보 `DarkMode_CFD` `[검증]`.
  - 탭 컨트롤 대신 왼쪽 목록으로 설정 영역을 나눈다 (탭은 다크 모드가 안 됨).
  - **한계:** 트레이·우클릭 팝업 메뉴는 문서화되지 않은 API(uxtheme 서수) 없이는 다크로 바뀌지 않아 밝게 남는다.
  - 전환: `WM_SETTINGCHANGE("ImmersiveColorSet")` 에서 다시 칠한다.
- **환영 창:** 첫 실행(또는 트레이 "도움말") — 소개, 조작(끌기·클릭·우클릭·트레이), 바로가기(캐릭터 관리·설정), 시작.
- **동의 창:** 화면 관찰 동의를 MessageBox 에서 전용 창으로 — 항목별 설명, 설정값, "이해했습니다" 체크 후 "동의하고 켜기". 동의 버전은 그대로(문구 변경, 범위 같음).
- **설정 창:** 바꾸면 "적용" 시 설정 파일 저장 + 즉시 반영(가능한 항목), 다시 시작이 필요한 항목은 표시.
  - 시작 프로그램 등록: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (사용자가 켤 때만).
  - 설정 파일은 앱이 다시 쓴다 → 사용자가 쓴 주석은 사라진다 (안내).
- **캐릭터 관리 창:**
  - 목록(아이콘 = 첫 프레임 / 3D 는 한 번 그린 썸네일), 정보(이름·버전·제작자·라이선스·렌더러·위치), 띄우기·마릿수(저장 후 다시 띄움).
  - 설치: 폴더 또는 `.zip` 을 끌어다 놓기 → 임시 폴더에 풀기(Windows 내장 `tar.exe`) → 패키지 밖 경로 검사 → `LoadPackage` + 모델·아틀라스 검사 → 사용자 캐릭터 폴더로 복사. 같은 id 가 있으면 확인.
  - 삭제: 사용자 캐릭터 폴더의 패키지만, 확인 후 휴지통으로 (되돌릴 수 있게).
  - 거부된 패키지와 이유 목록.

## 5. 진행 결과 (v0.2, 2026-10-19)

UI-01~UI-10 완료 ([진행 기록](../ui_report_ko.md)). 계획과 달라지거나 구체화된 점:

- **결정 ①~⑥ (2026-10-19 "추천안대로")** 그대로 구현: 팝업 메뉴는 밝게, 설정 저장은 다시 쓰기 + `.bak`, zip 은 Windows `tar.exe`, 삭제는 휴지통, 시작 프로그램은 `HKCU\...\Run`, 설정 창은 왼쪽 목록.
- **zip 검사 강화:** "임시 폴더에 풀고 검사" 에 더해, 풀기 **전에** zip 서명과 중앙 디렉터리를 직접 읽어 경로 이탈·심볼릭 링크·암호화·zip64·크기·개수를 거부한다 (tar 는 zip 외 형식도 읽으므로 zip 만 넘김). 푼 뒤에는 재분석 지점을 거부하는 트리 검사.
- **설정 저장 범위:** 앱의 지금 값이 아니라 디스크의 설정 파일을 다시 읽어 창이 다루는 항목만 덮어쓴다 (명령줄 재정의·실행 중 직접 고친 값 보존).
- **펫 크기**는 즉시 반영하지 않고 "다시 시작 필요" 로 표시한다.
- **3D 썸네일**은 화면 밖 텍스처에 한 번 그려 만든다 (스왑체인이 필요 없음).
- **ListView 머리글 다크 처리(UI-04)** 는 필요 없어짐: 목록은 모두 소유자 그리기 ListBox.
- **시험 전용:** 설치는 명령 9001 + `test_install.txt` (끌어다 놓기 자동화 불가), 삭제·덮어쓰기는 휴지통 대신 바로 삭제, 시작 프로그램은 시험 키, 환영 창은 `DP_TEST_NO_WELCOME`.
