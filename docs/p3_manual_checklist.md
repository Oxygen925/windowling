# P3 수동 확인 체크리스트 (실제 ChatGPT 계정)

자동 시나리오(`tests/scenario/p3_scenarios.ps1`)는 모의 서버로만 검증했다. 실제 계정 연동은 **사용자가 직접** 확인한다. 결과는 [p3_report.md](p3_report.md) §6 에 옮긴다.

## 준비

- **필요한 것:** Plus 또는 Pro 플랜 ChatGPT 계정. 문서에는 이 플랜이 ChatGPT plan usage 대상으로 적혀 있다.
- **실행 파일:** `build\x64-release\desktop-pet.exe`
- **설정 켜기:** `%LOCALAPPDATA%\DesktopPet\config.toml` 끝에 아래를 추가한 뒤 재시작한다. 트레이 메뉴 "AI 대화 사용" 으로도 켤 수 있지만, 이 방법은 실행 중에만 적용된다.
  ```toml
  [ai]
  enabled = true
  ```
- **포트 확인:** Codex CLI 등 `127.0.0.1:1455` 를 쓰는 프로그램이 있으면 먼저 끈다. 최초 로그인에 이 포트를 쓴다.
- **저장 위치:**
  - 자격 증명: `%LOCALAPPDATA%\DesktopPet\auth\` (DPAPI 암호화)
  - 로그: `%LOCALAPPDATA%\DesktopPet\logs\`

## 1. 로그인·승인

| # | 확인 | 기록 |
|---|---|---|
| 1-1 | 펫 클릭 → 대화창이 열림. 입력란에 포커스가 있음 | |
| 1-2 | "Continue with ChatGPT" → 기본 브라우저에 ChatGPT 승인 화면. 앱 이름이 "Desktop Pet" 으로 표시됨 | |
| 1-3 | 승인 → 브라우저에 "로그인 결과를 앱으로 보냈습니다" 표시. 대화창에 계정 이메일, "Using ChatGPT plan", 첫 안내(Got it) 표시 | |
| 1-4 | 모델 목록에 계정에서 쓸 수 있는 모델이 표시됨 | |
| 1-5 | 승인 화면에서 거부 → "승인을 거부해 로그인하지 않았습니다" | |
| 1-6 | 승인 중 대화창의 "로그인 취소" → 취소 안내 (브라우저 탭은 남음) | |

## 3. 로그아웃·복구

| # | 확인 | 기록 |
|---|---|---|
| 3-1 | "로그아웃" → "로그아웃했습니다". 다시 "Continue with ChatGPT" 를 누르면 계정 선택 화면만 거쳐 돌아옴. 워크스페이스 선택·동의 화면 없음(기존 등록 재사용, 문서 기대 동작) | |
| 3-2 | 앱 재시작 후에도 로그인 상태가 유지됨 | |
| 3-3 | ChatGPT 설정에서 이 앱("Desktop Pet") 연결을 해제한 뒤 질문 → 재로그인 안내 | |
| 3-4 | (가능하면) 사용량 한도에 도달했을 때 "Usage limit reached" 와 Manage usage 표시 | |
| 3-5 | 네트워크를 끊고 질문 → 연결 실패 안내, 앱은 정상 | |
| 3-6 | 로그 파일에 이메일·토큰·대화 내용이 없음 | |

## 4. 문서와 실제 동작 차이 (발견 시 기록)

다음 항목은 문서에 명시되지 않았거나 예시로만 나와 있다. 실제 동작이 다르면 로그(`[ai]` 줄)와 함께 적는다.

- 토큰 교환 `grant_type=authorization_code` 를 받아들이는지. 실패하면 로그에 `코드 교환 실패 http=... error=...` 가 남는다.
- 다시 로그인할 때 다른 포트(자동 선택)를 받아들이는지
- `/v1/models` 응답 형식. 모델이 0개로 표시되는지 확인한다.
