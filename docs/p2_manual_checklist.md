# P2 수동 확인 체크리스트

자동 시나리오(`tests/scenario/p2_scenarios.ps1`)로는 볼 수 없는 체감·사용성 항목이다. 결과는 [p2_report.md](p2_report.md) §6에 옮긴다.

- 실행 파일: `build\x64-release\desktop-pet.exe`. 빌드 시 `characters\` 폴더가 실행 파일 옆에 복사된다.
- 설정: `%LOCALAPPDATA%\DesktopPet\config.toml`. P1 때 생성된 파일에는 `[[pets]]` 가 없어 주황 1마리로 시작한다.
- 사용자 캐릭터 폴더: `%LOCALAPPDATA%\DesktopPet\characters\` (트레이 → 사용자 캐릭터 폴더 열기)

여러 캐릭터를 설정으로 띄우려면 `config.toml` 끝에 다음을 추가하고 재시작한다.

```toml
[[pets]]
character = "test-orange"
count = 2

[[pets]]
character = "test-blue"
count = 2
```

## 1. 캐릭터 차이

| # | 확인 | 기록 |
|---|---|---|
| 1-1 | 주황과 파랑이 색으로 구분됨 | |
| 1-2 | 파랑이 더 빠르고 더 자주 걸음 (walk 110px/s, 걷기 가중치 65) | |
| 1-3 | 파랑을 클릭하면 2초 앉음(Lua), 주황을 클릭하면 잠깐 쳐다봄(look) | |
| 1-4 | 파랑이 창 위에 있을 때 가끔 4초 앉음 (Lua `on_rest`) | |
| 1-5 | 4마리가 서로 겹쳐도 클릭·드래그가 맨 위 펫에 정상 전달됨 | |

## 2. 트레이·우클릭 메뉴

| # | 확인 | 기록 |
|---|---|---|
| 2-1 | 펫 추가 → 하위 메뉴에 "Test Orange (test-orange)", "Test Blue (test-blue)" 표시, 선택하면 위에서 떨어짐 | |
| 2-2 | 펫 위에서 우클릭 → "이 펫의 캐릭터 바꾸기" 에 현재 캐릭터가 체크되어 있고, 다른 캐릭터를 고르면 그 펫만 바뀜 | |
| 2-3 | 펫 위에서 우클릭 → "이 펫 제거" 를 고르면 그 펫만 사라짐 | |
| 2-4 | 트레이 아이콘 메뉴(펫이 아닌 곳)의 교체·제거 대상이 "마지막 펫"으로 표시됨 | |
| 2-5 | 8마리가 되면 "펫 추가" 가 비활성화됨 | |
| 2-6 | 사용자 캐릭터 폴더에 `characters\test-blue` 를 복사하고 `name` 을 바꾼 뒤 "캐릭터 패키지 다시 읽기" → 메뉴 이름이 바뀌고 펫이 다시 떨어짐 | |
| 2-7 | 메뉴 문구·순서가 자연스러운지 (개선 의견) | |

## 3. 회귀 (P1 체크리스트 중 다중 펫에서 달라질 수 있는 항목)

| # | 확인 | 기록 |
|---|---|---|
| 3-1 | 여러 펫이 걷는 동안 끊김·떨림이 없음 (30Hz 창 이동을 펫끼리 같은 틱으로 묶음) | |
| 3-2 | 전체화면 게임에서 모든 펫이 숨고, 나오면 다시 나타남 | |
| 3-3 | 잠금 → 해제 후 모든 펫이 정상 | |
