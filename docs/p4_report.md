## 2. 구현 요약

- **흐름:** 스케줄 → Privacy Guard → 캡처(펫 제외) → 요청 → 응답 검증 → 말풍선·이력·행동·TTS.
- **Privacy Guard** (캡처 직전 매번): 켜짐·동의 버전, 로그인·plan usage, 이미지 거부 모델, 사용량 한도(그날), 일시정지, 잠금·숨김·절전, 전체화면, 알림 상태(프레젠테이션 등), 제외 앱 창이 그 모니터에 보임, 자리 비움(기본 5분), 대화 중, 시간당 2회·하루 16회.
  - 건너뛴 사유는 코드로만 기록한다 (`[observe] skip reason=excluded_app`).
- **캡처:** 발화할 펫의 모니터를 WGC 로 1프레임 잡고 세션·Device 를 바로 닫는다.
  - 캡처 순간에만 펫·말풍선·대화창에 `WDA_EXCLUDEFROMCAPTURE`. 작업 스레드는 `DwmFlush` 2회 뒤 캡처한다.
  - WIC 로 긴 변 1024px 축소, JPEG 품질 80. 버퍼는 전송 뒤 `SecureZeroMemory`. 디스크에 쓰지 않는다.
  - WGC 노란 테두리는 기본값(표시) 그대로다.
- **요청:** `input_image`(data URL, `detail:"low"`) + 텍스트(로케일·시각·전경 앱 실행 파일 이름).
  - 구조화 출력 `text.format = json_schema(strict)`. 행동 이름은 그 캐릭터에 있는 `sit`·`look` 만 enum 으로 준다.
  - 400 으로 `text.format` 을 거부하면 안내문 JSON 으로 한 번 더 보내고, 그 모델은 이후 안내문 방식을 쓴다.
  - 이미지를 거부하면 그 모델에서는 관찰을 멈추고 대화창에 안내한다.
  - 대화 이력은 보내지 않는다. 발화 문장만 그 펫의 이력(RAM)에 assistant 항목으로 남긴다.
- **응답 검증:** `should_speak` 필수, 텍스트 정리(제어 문자 제거, 120자), 감정 6종 외 → neutral, 행동은 허용 목록 외 → 무시. 응답 원문은 쓰고 나면 지운다.
- **동의:** 트레이 "화면 관찰 켜기…" → 보내는 것·빈도·대상·저장 안 함·건너뛰는 경우·테두리·끄는 법·개인정보 경고를 보여 주는 동의 화면(기본 버튼 "아니요").
  - `observe_state.json`: `enabled`, `consent_version`, `consented_at`, `sent_unix`. 설정 파일로는 켤 수 없다.
- **중지:** 일시정지(1시간·오늘·해제할 때까지), 끄기, 대화 시작, 숨김·잠금·전체화면·펫 제거 → 진행 중 요청 즉시 취소, TTS 중지.
- **TTS:** WinRT `SpeechSynthesizer`(OneCore 음성) → WAV → XAudio2. 출력 큐 1개, 대기 2개. 단어 경계 시각을 받아 두는 자리만 있다(립싱크용).
  - 기본은 자율 발화만 읽는다. `[tts] read_chat_replies` 로 대화 응답도 읽는다.
- **경계:** `IAiProvider`(SIWC 구현 1개), `ITtsProvider`(WinRT 구현 1개). 로컬 LLM·로컬 AI TTS 는 이 경계로 추가한다.
- **테스트 전용 인자** (`--ai-endpoint` 가 127.0.0.1 일 때만): `--observe-interval-sec=N`, `--observe-dump=path`.

### 3.2 확인하지 못한 것 (사실과 추정 구분)

- **펫 제외:** 검증용 캡처 1장을 직접 열어 보았고 펫·말풍선은 보이지 않았다. 그러나 제외를 끈 대조 캡처를 찍지 않았으므로 "그 위치에 펫이 있었는데 빠졌다" 는 확인하지 못했다 `[검증]`. 확인한 캡처 파일은 바로 지웠다.
- **자동 시험이 없는 조건:** 자리 비움(`GetLastInputInfo`, 자동 시험에서는 끔), 알림 상태(`SHQueryUserNotificationState`), 세션 잠금 중 관찰(P1 의 잠금 처리를 재사용).
- **WGC 테두리:** 실연동에서 보이지 않았다 (§3.3). 동의 문구는 트레이 표시로 바꿨다.
- **펫 제외:** 대조 캡처 없이 "펫이 보이지 않음" 만 확인했다 (자동 시험 캡처 1장, 실연동은 이미지를 보지 않음).
- **TTS 중지:** 전체화면 진입·펫 제거 때 재생을 멈추는 코드는 있으나 자동 시험은 없다. 트레이 툴팁도 눈으로 확인하지 않았다.
- **펫 3마리 이상:** 2마리로만 시험했다 (선택 규칙은 마릿수와 무관).
- **실제 SIWC:** 이미지·구조화 출력 지원은 문서 기재만 확인했다 (미지원 목록에 `text.format` 없음, 이미지 "selected model accepts them" 일 때 지원).

## 4. 성능 (관찰 1회, 시나리오 로그)

| 항목 | 값 | 비고 |
|---|---|---|
| 캡처 (Device 생성 + 1프레임 + 복사) | 146~327ms | 목표 100ms 초과. 작업 스레드에서 실행되어 UI 는 막지 않는다. Device 생성이 대부분으로 추정 `[검증]` |
| 축소 + JPEG | 23~29ms | |
| JPEG 크기 | 57~71KB | base64 로 약 4/3 배 |
| TTS 합성 | 156~453ms | 첫 회가 가장 길다 (엔진 생성) |

- 관찰 꺼짐: 모듈을 만들지 않는다. 동의 기록 파일을 1번 읽는 것뿐이다.
- 관찰 켜짐·대기 중: 다음 시도 마감 1개(15~30분 뒤)만 걸고 캡처 객체는 없다 → 추가 기상은 구조상 15~30분에 1번이다. **측정하지 않았다.**
- 순간 메모리 증가는 측정하지 않았다.

## 5. 사용자 확인이 필요한 것

- [실연동 절차서](p4_live_verification_ko.md)로 실제 계정 확인 (P4 최종 완료 조건).
- 계획 §6 추천안 (미확정): P4-R1·R2·R4·R6~R11, 기본 제외 목록, 테두리 유지.
- 계획과 다르게 구현한 것: TTS 음성은 전역 1개(`[tts] voice`)다. 계획 §2.6 의 "펫(캐릭터)별 음성" 은 하지 않았다. 캐릭터 패키지에 음성 항목을 넣을지 정해야 한다.
- 캡처 시간 100ms 목표: Device 를 관찰이 켜져 있는 동안 유지하면 줄일 수 있다. 대신 대기 중 메모리가 늘어난다. 현재는 유지하지 않는다 (추천 미확정).

## 6. 후속 (2026-10-19, B 결정 반영)

- **B11:** 허용 행동 설정 `[observe] allowed_behaviors` (idle·sit·look·walk, 기본 sit·look). 기본 제외 목록에 메신저 4종 추가. 동의 화면·관찰 상태에 설정 안내, 트레이 "관찰 설정 열기".
- **B12:** 캐릭터 manifest `[voice]` (name·ai_voice·rate). 없으면 전역 `[tts]`.
- **로컬 AI TTS:** HTTP(OpenAI 호환 `/v1/audio/speech`, 로컬 주소만)·명령 실행(`{text}`·`{text_file}`·`{out}`·`{voice}`·`{speed}`). 실패하면 읽지 않는다. VOICEVOX 호환은 보류. 안내: [local_tts_ko.md](local_tts_ko.md)
- **B14:** 대조 캡처로 펫 제외 확인 (펫 영역 배경색 이탈 비율: 제외 켬 0.000 / 끔 0.636).
- **빌드:** 개발용 캐릭터 복사를 빌드마다 하도록 바꿨다 (패키지만 바꾸면 반영되지 않던 문제).
- **시험:** 단위 core 51/51·platform 5/5, P4 시나리오 **26/26** (T2 HTTP·캐릭터 음성, T3 명령 실행·한일 텍스트 전달, T4 실패 시 읽지 않음, B14 대조 캡처).
- **확인하지 못한 것:** 실제 로컬 AI 엔진(sherpa-onnx·Supertonic·Kokoro)과의 연결, sherpa-onnx 의 한글·일본어 인자 처리.
