# ADR-09 Hit-test(클릭 통과) 방식 — 잠정

- 상태: **잠정 결정** (2026-10-13, P0 단축 검증 기준). 정식 측정·수동 확인 후 확정
- 관련: 계획서 §3.3, E1 / 보고서 `docs/p0_report.md` §6

## 결정

**방식 B (`SetWindowRgn`, 알파 마스크 Region)를 1순위로 채택한다.** 방식 C(`UpdateLayeredWindow`)는 2D 전용 폴백 후보로 유지하고, 방식 A(동적 `WS_EX_TRANSPARENT` 토글)는 기본값에서 제외한다.

## 근거 (E1 자동 검증, SendInput 실제 입력, 30fps 애니메이션 중)

| 항목 | A | A-fast(16/33ms) | B | C | none |
|---|---|---|---|---|---|
| 투명 영역 클릭·휠 → 뒤 창 | 통과 | 통과 | 통과 | 통과 | 실패 |
| 불투명 클릭 → 펫, 포커스 유지 | 통과 | 통과 | 통과 | 통과 | 통과 |
| 빠른 접근 후 첫 클릭 | **실패(뒤 창으로 샘)** | 통과 | 통과 | 통과 | 통과 |
| 드래그 150px | 통과 | 통과 | 통과 | 통과 | 통과 |
| 번갈아 클릭 5+5 (도착 15ms 후 클릭) | **불투명 2/5 누락** | **불투명 2/5 누락** | 통과 | 통과 | 실패 |

- A는 커서 확인 주기만큼 경쟁 구간이 남는 구조적 한계가 있다(주기를 16ms로 줄여도 누락).
- B·C는 OS가 입력 시점에 판정하므로 누락이 없었다.
- 비용: 정지 시 A/B/C 모두 CPU 0.005% 이하. 30fps 1마리 B 0.16~0.23%, A 0.11%, C 0.04%(단축 측정).

## 결과·제약

- B는 Region이 **DComp 출력도 잘라낸다**(확인됨). 말풍선·라벨은 Region에 포함하거나 별도 창으로 그린다.
- B는 알파 임계값(현재 32) 미만 가장자리가 잘린다. 안티앨리어싱 품질은 수동 확인 필요.
- 애니메이션 프레임마다 Region을 재계산한다(현재는 콘텐츠가 바뀐 펫만). 3D 모델은 매 프레임 마스크 생성(GPU readback 또는 근사 형상)이 필요해 비용이 커질 수 있다 → P5에서 재평가. 3D는 바운딩 형상 Region 또는 C 방식 비교를 다시 한다.
- C는 GPU 경로(DComp·3D·D2D 공유 Device)와 함께 쓸 수 없어 기본 경로로는 부적합.

## 미확정·미검증

- 캐릭터 중첩 상황, 실제 사람 손 조작 체감, 관리자 권한 창 위 동작, 다중 모니터·혼합 DPI
- 정식(10분 × 3회) 성능 측정

## 추가 (2026-10-14): Region 갱신 단위

- M1 계측 결과, 걷기 중 앱 비용의 큰 부분은 `SetWindowRgn` 호출 자체다(Region 계산이 아님).
- 선택 옵션 `[input] hit_region = "clip"` 을 둔다.
  - 동작(클립) 프레임들의 합집합 Region 을 동작이 바뀔 때만 설정한다.
  - 5마리 걷기 기준 사이클 CPU 가 0.42 → 0.27% 로 줄었다.
  - 대신 걷는 동안 프레임 사이에서 투명해진 일부 픽셀이 클릭을 받을 수 있다.
- **기본값은 `"frame"` (프레임별 정밀 Region) 을 유지한다.** 클릭 통과 정확성을 우선한다(사용자 결정).
- 기본값 변경은 다양한 크기·애니메이션에서 클릭 오차를 측정한 뒤 다시 검토한다.

## 추가 (2026-10-19, P5: 3D)

- 3D 펫은 **GPU 알파 readback → Region** (사용자 결정). 그릴 때 백버퍼를 staging 으로 복사(최대 10Hz)하고 다음 프레임에 기다리지 않고 읽는다. 같은 마스크면 `SetWindowRgn` 생략.
- Region 은 창의 보이는 부분도 자르므로, 마스크를 4px(DPI 비례) 넓혀 Region 지연(최대 0.1초 + 1프레임) 동안 움직이는 부분이 잘리지 않게 한다. 넓힌 부분은 투명해도 클릭을 받는다 `[검증]`.
- 측정: 3D 1마리 정지 Region 갱신 9.9회/초, CPU 0.107% ([P5 보고서](../p5_report.md) §4).
- `hit_region = "clip"` 은 3D 에 적용하지 않는다.
