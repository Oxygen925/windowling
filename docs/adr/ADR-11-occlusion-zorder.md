# ADR-11 부착 중 가림·Z-order 정책 — 확정 (P1)

- 상태: **확정** (2026-10-13, 사용자 결정 P1-D2). 유예 시간 값은 미확정 초기값
- 관련: P1 계획 §3.3, 시나리오 W6a·W6b

## 결정

1. 펫 창은 topmost 를 유지하고, 서 있는 창의 발 지점이 다른 창에 가려지면 **유예 시간(초기 250ms)이 지난 뒤** 낙하한다.
2. 순간 가림(유예 시간 이내)은 무시한다.
3. topmost 설정은 **표시·재표시·숨김 해제 때만** 한다. 이동은 `SWP_NOZORDER`. 다른 topmost 창 위로 올라가려고 반복 설정하지 않는다.
4. 비 topmost + 호스트 창 바로 위 배치(C안)는 별도 비교 실험으로 남긴다(P1 완료 조건 아님).

## 근거

- 시나리오: 순간 가림(100ms) 낙하 없음, 지속 가림 → 유예 후 낙하 확인.
- 다른 프로세스의 `SetWindowPos(HWND_TOP, SWP_NOACTIVATE)`는 전경 창 위로 올라가지 않는다(확인). 즉 일반 창끼리의 Z-order 변화는 대부분 사용자 활성화(전경 변경)로 일어나며 `EVENT_SYSTEM_FOREGROUND`로 감지된다.
- 위치 변경과 함께 Z-order가 바뀌는 경우를 대비해, `LOCATIONCHANGE` 이후 Z-order를 최대 100ms 간격으로 다시 읽는다(방어 코드, 필요성 미검증). 창 이벤트 폭주(R3)에서도 CPU 0.25%.

## 미확정·미검증

- 유예 시간 값(250ms)의 체감 적정성
- `EVENT_OBJECT_REORDER` 발생 조건
- 다른 topmost 앱(오버레이·작업 관리자 "항상 위") 공존 시 동작
