# ADR-12 전체화면 판정과 숨김 — 잠정

- 상태: **잠정** (2026-10-13). 직접 출력 복귀 측정(P1-D5) 반영 완료. 다중 모니터·다른 게임 확인 후 확정
- 관련: 기준선 §4.3, P1 계획 §3.7, P0 보고서 §6.2, 시나리오 W12

## 결정

- 판정: 전경 창(자기·셸 창 제외)이 모니터를 **98% 이상** 덮으면 그 모니터를 전체화면으로 본다. 최대화 창은 작업 표시줄을 덮지 않아 제외된다.
  - 예외 목록: `always_show_exe`(숨기지 않음), `always_hide_exe`(덮음 비율과 무관하게 숨김), 실행 파일 이름 소문자 비교.
  - `SHQueryUserNotificationState`는 판정에 쓰지 않고 로그로만 남긴다.
- 숨김: 그 모니터의 펫 창을 **`SW_HIDE`**. 물리·행동·렌더·타이머 정지. 다른 모니터의 펫은 유지.
- 해제: 전경 변경·창 위치 변경 시 재판정. 해제되면 낙하 상태로 다시 배치(숨긴 사이 창 배치가 바뀌었을 수 있음).

## 근거

- P0 E6: 게임 위에서 보이지 않는(가려진) 펫 창만으로도 게임이 DWM 합성으로 바뀐 사례 → 렌더 중지만으로는 부족, 창을 숨긴다.
- 시나리오 W12: 전체화면 창 전경 → 숨김, 원래 크기 → 표시 확인.
- 테두리 없는 창을 `SW_MAXIMIZE` 하면 작업 표시줄까지 덮어 전체화면으로 판정됨(규칙대로 동작).

- 직접 출력 복귀 측정(P1 보고서 §4.1): 게임 복귀 첫 프레임부터 직접 출력, 펫 없는 기준선과 차이 없음(한 프레임 이내).

## 미확정·미검증

- 브라우저 F11·동영상 전체화면의 실제 판정
- 다중 모니터에서 다른 모니터의 펫 유지
