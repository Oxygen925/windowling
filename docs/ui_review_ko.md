# UI·UX 점검 (P6 전, 2026-10-19)

**방법:** 모의 서버로 앱을 띄워 대화창을 캡처하고(앱 창만, 실제 계정 아님), 트레이 메뉴·대화상자·말풍선은 코드로 확인했다.

## 1. 사용자에게 보이는 화면

| 화면 | 현재 | 만든 방식 |
|---|---|---|
| 트레이 아이콘 | Windows 기본 앱 아이콘(`IDI_APPLICATION`), 툴팁 "Desktop Pet" | Shell_NotifyIcon |
| 트레이·펫 우클릭 메뉴 | 한 단계 목록 약 20개 (펫 추가·교체·제거, AI, 화면 관찰, TTS, 숨기기, 설정 파일, 폴더, 종료) | Win32 메뉴 |
| 대화창 | 회색 Win32 컨트롤. 계정·로그인, plan 표시·Manage usage·모델, 안내문, 기록(여러 줄 EDIT), 입력·보내기, 상태 | Win32 |
| 말풍선 | 둥근 사각형 + 꼬리, 크림색 배경, Segoe UI 14px | D2D·DirectWrite |
| 동의 화면·관찰 상태 | MessageBox 긴 글 | MessageBox |
| 설정 | `config.toml` 직접 편집 (트레이 "설정 파일 열기"·"관찰 설정 열기") | 메모장 등 |
| 첫 실행 | 안내 없음. 펫이 나타나고 트레이에 아이콘만 생김 | — |

## 2. 발견한 문제

| # | 문제 | 영향 | 크기 |
|---|---|---|---|
| U1 | 앱 아이콘이 없다 (트레이·대화창·작업 표시줄 모두 기본 아이콘) | 다른 앱과 구별 안 됨, 미완성으로 보임 | 작음 (아이콘 에셋 필요) |
| U2 | 메뉴가 길고 한 단계 (약 20개) | 찾기 어려움. 펫 메뉴와 트레이 메뉴가 같음 | 작음 |
| U3 | 설정이 TOML 파일 편집뿐 | 일반 사용자에게 어려움. 바꾼 값은 다시 시작해야 적용 | 큼 (설정 창) |
| U4 | 첫 실행 안내 없음 | 무엇을 할 수 있는지(드래그·클릭·우클릭·트레이) 알기 어려움 | 작음 |
| U5 | 대화창: 기록이 일반 텍스트 상자, "나:" 접두어, 회색 기본 스타일, 아래 상태 줄 공간이 비어 보임 | 대화 앱으로 보기 아쉬움 | 중간 (꾸미기) ~ 큼 (말풍선형 기록) |
| U6 | 대화창: 영어·한국어가 섞임 ("Continue with ChatGPT", "Manage usage", "Got it", "You're using your ChatGPT plan") | 일부는 SIWC UI 지침 문구 | 작음 (지침 확인 필요) |
| U7 | 대화창 제목 "Test Blue 와(과) 대화" | 어색한 조사 | 작음 |
| U8 | 로그인 전 모델 목록이 빈 채로 보임 | 혼란 | 작음 |
| U9 | 동의 화면·관찰 상태가 긴 MessageBox | 읽기 어렵고 버튼이 예/아니요뿐 | 중간 (전용 창) |
| U10 | 다크 모드 미지원 (대화창·대화상자) | Windows 다크 테마에서 눈에 띔 | 중간 |
| U11 | 언어가 한국어 고정 (일부 영어) | 공개 배포(P6) 대상에 따라 문제 | 큼 (다국어 구조) |
| U12 | 캐릭터 관리: 추가·교체만 메뉴, 설치·삭제는 폴더 직접 | P6 의 "압축 팩 드래그 설치" 와 연결 | 중간 |

## 3. 잘 되어 있는 것 (유지)

- 펫은 포커스를 뺏지 않고 투명 부분 클릭이 통과한다 (ADR-09).
- 말풍선은 클릭 통과·자동 숨김·DPI 대응.
- 대화창은 DPI 변경에 맞춰 다시 배치한다.
